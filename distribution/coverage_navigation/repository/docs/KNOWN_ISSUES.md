# 已知问题与尚未验证项

发布准备保持现有算法行为；以下问题公开保留，未在文档整理中声称修复。

1. 换向点附近缓存后续路径接续可能反复失效，引发重新搜索。短段的 SUCCEEDED 终态
   与实际有向进度复核存在已发现的缺口，需专门修复与实车回归。
2. Hybrid 有有效路径仍可能因 TEB 执行无进展反复重试，最终暂停。第三轮实测有此情况，
   不能将“规划成功”视为“转场成功”。
3. 两条并行搜索未记录获选 lane/TID 及逐路指标，已有日志不能统计采用率；expansions
   是两路总和。可观测性补充尚未实现。
4. 首入场由 Navfn+TEB 执行，可能受局部外廓障碍检查或长路径影响；入场耗时不能全归给
   Hybrid 搜索。
5. 默认清扫检查窗口为 5 m，需按传感器清除范围和制动能力验证；未知空间、外廓和边界
   检查保留。窗口之外的旧障碍数据没有被此算法自动删除。
6. 状态机仍使用 M2/原项目的状态接口；“可克隆构建与运行合成示例”不代表任意新底盘
   无适配即可移动。ROS 2、其他运动学、CPU0–CPU5 逐核性能和最优速度参数均未验收。

问题复现时请记录代码提交、参数、地图分辨率/外廓、任务阶段、规划结果 outcome、
路径挡位、实际 odom/TF、控制指令及暂停原因。公开 issue 前去除现场敏感数据。
