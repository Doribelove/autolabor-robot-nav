# 已知问题与尚未验证项

以下问题公开保留，未在文档整理中声称修复。

1. 自动转场重试会在障碍、目标外廓占据或局部执行持续不可行时一直保持任务并等待下一轮；
   它不会把“规划成功”当作“执行成功”。长期无法恢复的现场需要操作员取消，安全暂停仍
   不会被自动越过。
2. 2026-09-14一轮最终完成的实车实验中记录到一次未跟踪GoalHandle的晚到回调错误，未
   改变任务终态；其产生条件和是否影响其他时序仍需专门复现。
3. 两条并行搜索未记录获选 lane/TID 及逐路指标，已有日志不能统计采用率；expansions
   是两路总和。可观测性补充尚未实现。
4. 首入场由 Navfn+TEB 执行，可能受局部外廓障碍检查或长路径影响；入场耗时不能全归给
   Hybrid 搜索。
5. 默认清扫检查窗口为 5 m，需按传感器清除范围和制动能力验证；未知空间、外廓和边界
   检查保留。窗口之外的旧障碍数据没有被此算法自动删除。
6. map/odom相关阈值、暂停后制动记录窗口和入口容差需要按目标车辆速度、定位频率及制动
   距离验证。不能解释的map位姿变化仍会按定位不连续处理。
7. 状态机仍使用 M2/原项目的状态接口；“可克隆构建与运行合成示例”不代表任意新底盘
   无适配即可移动。ROS 2、其他运动学、CPU0–CPU5 逐核性能和最优速度参数均未验收。

问题复现时请记录代码提交、参数、地图分辨率/外廓、任务阶段、规划结果 outcome、
路径挡位、实际 odom/TF、控制指令及暂停原因。公开 issue 前去除现场敏感数据。
