# 独立发布副本验证（2026-09-16）

以下是维护者本机对独立白名单导出的验证。导出没有挂载原工作区的
`build/devel/install`、私有依赖 sysroot、设备或现场地图。远端 GitHub Actions 的结果
以仓库 Actions 页面和 README 徽章为准，不能用这份本地记录代替。

## 环境

* 宿主机 ARM64 Linux；容器 Ubuntu 20.04 / ROS Noetic。
* 构建基础镜像 `ros:noetic-ros-base-focal`，本次解析摘要为
  `sha256:72b8bc59035dc0a5b8e07aae28c16caa84192971d72d207c72ed734fb1d5e97d`。
* 依赖由仓库 Dockerfile 从公开 apt 源安装，源码通过 `COPY` 导入。
* `tools/build.sh` 以 Release 模式编译三包，消息、服务、插件、定制 TEB 和测试均从
  干净导出重新生成。
* 测试容器使用 `--network none`，仅有 lo；没有连接真实 ROS 图或硬件。

## 实车观察边界

2026-09-14 当前算法完成一轮 10 段覆盖，实测 275.604 秒；一次 Hybrid 整轮重试耗尽后
自动继续，最终没有进入 `PAUSED`。26 次 Hybrid action 均以 `SUCCEEDED` 返回，3 次目标
footprint 占据/未知由后续重试恢复，另有 9 次低进展取消。整板 CPU 平均 28.55%、峰值
53.42%，move_base 峰值约 1.51 核。该记录只说明一次指定场地运行，不代表所有车辆、
障碍、定位重置或人工恢复场景均已验收。

## 尚不能据此声称

* 本机通过不等于远端 CI 通过；推送后的实际 workflow 必须独立成功。
* 干净容器实测为 ARM64；x86_64 CI、不同底盘和传感器接入需要各自结果。
* 合成场景没有驱动车辆，不能替代转场、制动距离和安全链路的实车验收。
* apt 包下载及浮动镜像 tag 可能变化；本记录保留本次基础镜像摘要，源码由
  `SOURCE_MANIFEST.json` 逐文件校验，但不保证未来下载永久逐位相同。
