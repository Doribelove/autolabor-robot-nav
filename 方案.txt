1. 4 路环视相机（前/右/后/左）各输出独立 RGB 图像，每帧携带图像曝光时间戳；GDC 硬件完成去畸变。
2. 预处理（resize、归一化）在 CPU/VPU 完成，适配 YOLO 输入。
3. BPU 模型（均为 hbm）：YOLO11s-GAM 检测 + YOLO11s-cls 材质分类，启动时一次性 hrt_model_load 驻留内存，运行时不重复加载；J6M 单 BPU，多任务串行排队。
4. 推理调度（优先级 P0>P1>P2）：
   P0 前向：每帧新图触发 GAM+cls，下一帧直接触发，不积攒队列；
   P1 左右：每 N 帧触发一次，触发后计数器清零；
   P2 后向：仅倒车/大角度转向时触发，纯前进不推理；
   维护 BPU 队列深度，积压超阈值时按 后向→左右 顺序丢弃任务，始终保证前向推理。
5. 单路 BEV 定位（地面平面假设）：
   框底边中点不能落在天空 / 图像边缘无效区域，对每个 2D 框取"底边中点（地面接触点）"；使用该路相机【静态内参 + 静态车体外参】，将底点反投影到车体坐标系地面 z=0，得 BEV 坐标 (x,y)；
   有效域过滤：距离在 0.3~10 m，否则丢弃；再用【图像曝光时刻的源时刻车体位姿】（FAST-LIO），将 (x,y,0) 转换为 map 全局坐标。
6. 跨相机融合（同一曝光批次）：
   优先在车体 BEV 平面做去重（硬件同步时四路曝光时刻一致）；
   两目标同时满足：① 时间戳差 ≤ 100 ms；② map 平面距离 ≤ 0.4 m
   且类别一致，判为同一垃圾，保留置信度最高者，其余丢弃；
   不满足则分别保留。
7. 跨帧时序融合 / 地图目标管理：
   维护已确认垃圾目标列表（map 坐标、类别、材质、置信度、观测计数）；
   新检测与已有目标按 map 平面距离 + 类别匹配：
   命中则更新坐标、累计置信度（多帧观测才置为 confirmed）；
   未命中连续 5 帧才新建目标；已存在目标连续 5 帧丢失才删除。（复用部分原有逻辑）
8. 输出：稳定的垃圾目标（map 坐标 + 类别 + 材质 + 置信度），
   消息格式兼容 autolabor_fod_vision，标记到地图，作为定点清扫任务输入；整车避障仍由 MID360 负责，相机结果不进入避障规划。
9.qt新增可视化鸟瞰图界面（鸟瞰图只做显示调试，YOLO 推理永远跑在 GDC 输出的去畸变透视图，禁止在鸟瞰图上做目标检测）。
