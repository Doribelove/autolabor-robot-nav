# TEB 固定档位与 cusp 条件续接验证（2026-09-04）

## 结论

当前“直接 Hybrid A* + 按 cusp 拆 action + TEB 闭环 + 条件续接”架构完成了 A 区正常回归、
入口位姿偏差和清扫线冲出隔离 Gazebo 测试。最新配置把最终入口搜索区域放宽为
`0.30 m / 20°`，外层入场验收同步放宽为位置/横向 `0.40 m`、航向 `25°`，中间 cusp
保持 `0.25 m / 0.20 rad`，cusp 有向横向与清扫完成横向阈值也保持 0.30 m。最新 3 轮
正常回归和 1 轮入场偏差回归均为 `COMPLETED`，
没有碰撞、未知区越界、曲率违规、非零速换挡、持续卡停或左右摇摆。

cusp 处理不是每到一点就重规划。每个固定档位段停车后先检查实测位姿能否在旧后缀前
0.30 m 内构造同档切向连接，要求弦误差不超过 0.10 rad、半径不小于 1.35 m。满足时裁掉
旧锚点继续；不满足时才从实测位姿到原清扫线最终入口重算完整剩余连接。最新三轮记录
20 次事件重算、0 次 1 Hz 无条件搜索；同时观察到了“保留后缀”和“整段重算”两个分支。

### 取消 1.20 m 累计前进门的仿真分支

仅在隔离仿真树中删除 `sweep_entry_recovery_max_forward_distance_m` 及其候选拒绝分支，
保留 4.0 m 总长门、倒车低代价、碰撞/未知区/曲率检查、Hybrid 目标区域和实测 hand-off。
权威工作区和 J6M 未同步该实验改动。

随后在 A 区第二条清扫线入口前完成四组双向扰动：`±0.35 m / ±0.25 rad` 和
`±0.60 m / ±0.50 rad`。四次任务均 `COMPLETED`，恢复执行时间为 5.108--8.774 s，
注入到重新进入清扫为 5.656--9.658 s；实际恢复路径为 1.095--2.185 m，累计实际转角
30.69--46.91°，最大弦偏差 0.301--0.886 m。没有大幅前进绕圈、持续卡停、左右摇摆、
碰撞、未知区采样或曲率违规，全部换向均经过零速。

最大正向扰动的实际累计前进为 1.225 m、倒车为 0.960 m，但这是初始计划执行和一次

偏离数据见 `CURRENT_ARCHITECTURE.md` 列出的四个结果目录。

且 `unconditional_1hz_replans=0`。因此当前架构保留 move_base 1 Hz 校验，但禁止 1 Hz
无条件 Hybrid 搜索。
