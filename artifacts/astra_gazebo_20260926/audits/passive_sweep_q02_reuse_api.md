Q02 provides a reviewed fixture candidate, with first live qualification still pending. A navigation stage should own a new runner/launch and new adapter; the frozen Q02 contract and node deliberately accept only their two10s fixture identities.

Reusable frozen evaluation interfaces are:

- `dense_sweep_p03.authenticate_closure(path, start_ns, end_ns)` verifies actual evidence bindings and authorized-node/engine/writer audits for the requested interval.
- `dense_sweep_p03.read_p03_bag(path)` reads Pre/End model/link rows, step statuses and runtime metadata without a ROS master.
- `dense_sweep_p03.assess_records(**records, world_xml, start_ns, end_ns, closure_audit)` returns the engineering-sweep report, per2ms scalar/body-budget rows and coarse geometry endpoints. **Calling this function alone omits the CLI's expanded-URDF mass/COM/body/radius/count cross-check and before/after input/closure rehash.** A new adapter must retain those obligations.
- The complete frozen CLI is `dense_sweep_p03.py --bag B --world W --urdf U --closure C --start-ns N --end-ns M --output NEW_DIR`. It writes report.json, endpoints.csv and derived interval-budget JSONL. This interval file contains bounds, not duplicate model/link/contact payloads. Q02 keeps it for first qualification; a future compact/streaming writer needs a new reviewed adapter, without changing the bound math or old files.
- `evaluate_episode.read_bag(path)`, `WorldCollisions(world_xml)` and `contact_audit(rows_by_source_ns, world, start_ns, end_ns, robot_name, actor_names, issues)` provide independent whole-contact classification. Preserve original stamp lists and run duplicate/order/coverage checks before indexing; otherwise duplicate messages can be silently collapsed. Only wheel-link/ground support is legal for the robot. Empty packets do not imply collision-free motion.
- `geometry.RobotCollisionModel(urdf_xml)` and full compound projection remain the geometry source for nominal/legacy checks. Runtime P03 evaluation uses actual merged collision metadata and authenticates it against the saved expanded URDF; do not replace that with a chassis radius.

The physics bag needs `/astra/p03/pre_models`, `/astra/p03/pre_links`, `/astra/p03/end_models`, `/astra/p03/end_links`, `/astra/p03/step_status`, `/astra/p03/runtime_metadata`, `/astra/physics_contacts`, `/astra/physics_metadata` and `/clock`. Keep the existing50Hz `/astra/world_models` and `/astra/world_links` for navigation/report joins. Physical driver evidence is `/m2_driver/physical_status`, `/m2_driver/physical_metadata`, `/m2_driver/actuator_target`, `/m2_driver/actuator_commanded_effort`, `/m2_driver/command_ingress`, `/odom` and `/joint_states`. A navigation stage additionally needs its normal sensor, map/route consumer, command, mode/gate, input-health and decision evidence. P05 ingress is actual driver acceptance time; ordinary Twist has no source stamp.

Reusable lifecycle logic is recorder TCPROS connection readiness before unpause; exact runtime expanded-URDF capture; loopback master/process ownership; pre/end actual ELF maps with hash+BuildID; authorized node/PID/executable snapshots and ongoing roster checks; a single reviewed service gateway; bounded warmup; active source-clock liveness; final pause; then **two stable Gazebo get_world_properties.sim_time queries on the2ms lattice and all dense streams drained to that watermark**. Preserve a bag-side posthoc coverage check too: collector completeness does not prove the independent rosbag subscriber retained everything. Q02 uses the new service gateway to spawn the robot itself; no external spawn node is hidden from that journal.

World/URDF components can be reused by composing `libastra_physics_metadata_p03_plugin.so` with the retained `libastra_dense_evidence_plugin.so` in a newly generated world, retaining actual box/cylinder geometry, and using the now-explicit P05 physical model with the separately qualified gain. The generator and runtime closure must bind exact world bytes, expanded URDF, actual plugins/controller/actor sources and binaries. Actor updates remain bounded Begin jumps within the declared simulation interpolation model; they are not continuous physical trajectories. Dynamic nonrobot models, unknown shape types, altered body modes or unreviewed writers require fresh qualification.

Q02-specific portions that must not be imported as navigation policy are `contract()`, `CommandSchedule`, `world_sdf()`, the two seed/identity reservations, fixed200-command gate and exact fixture node roster. The collector's helpers are nested in its fixture entry, so a new navigation adapter should copy the reviewed lifecycle into its own versioned file or factor new common helpers under new ownership, with offline equivalence tests. Pure `source_coverage`, `read_bound` and process/ELF helpers are callable, but their expected-role/roster constants remain Q02-specific. The new navigation source review must derive its own roster/writer audit from actual allowed nodes and service paths.

For matrix scaling, keep one lz4 bag as the only dense raw payload. Save source hashes, counts, missing/duplicate diagnostics, extrema, restricted-time/goal summary and a small set of failure examples. Store source-phase native PNGs outside the bag. Whole-contact JSON should retain counts and selected examples rather than every legal support contact. Q02 already follows this policy; its collector JSON contains stamps/status/audits rather than dense poses. The reused CLI's derived interval-budget trace can be gzip/zstd compressed by a new writer while preserving an authenticated uncompressed digest, or reduced after a separately reviewed streaming assessment. Do not silently delete or rewrite historical artifacts. RTF/CPU/RSS observations are descriptive without an observer-off paired experiment.
