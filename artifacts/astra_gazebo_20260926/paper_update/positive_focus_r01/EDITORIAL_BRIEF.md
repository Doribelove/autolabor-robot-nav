# 论文编辑方向：先写成立的成果

建议题目：**面向 Ackermann 移动机器人的候选级安全局部导航与仿真特权轨迹排序学习**。
题目不承诺一般场景下优于 TEB/DWA，也不承诺实车验证。

## 重点贡献与证据

| 主线 | 可写的最强结论 | 证据位置 |
|---|---|---|
| 候选级动作与硬验证 | 以可执行 Ackermann 候选替代高维 TEB 参数动作，提供候选条件预测、硬验证与 certified-stop | `materials/paper/FAM_TEB_EXISTING_EVIDENCE_TECHNICAL_DRAFT.tex` 方法章及 `materials/paper/evidence/` |
| 单行人交互规划验证 | 三个冻结单反应式行人 Gazebo 模板中，候选条件安全规划方法对固定 actual TEB 0.8.4 的配对时间下降 12.9288%，单侧 97.5% 下界 12.7253%；双方均完成 30/30 目标 | 技术稿中对应实验章；内部索引见 `EVIDENCE_CROSSWALK_INTERNAL.md` |
| 传感器级学习验证 | 四类冻结快速传感器级任务中，特权轨迹排序学习方法相对解析先验下降 8.402444%，双侧 97.5% CI [3.484003%,13.713459%]，通过冻结主门 | `materials/paper/evidence/canonical_results.json` 和对应正式 assessment |
| 工程可复核性 | 完整保留数据、统计、失败回合、图和哈希；规划与学习两项证据分别报告 | `materials/paper/README.md`、`materials/formal_gazebo_evidence/`、`materials/paper/EVIDENCE_MANIFEST.json` |

## 建议正文结构

1. 绪论：Ackermann 动态交互、动作投影错位、论文问题和贡献。
2. 方法：可行候选、候选条件预测、硬 verifier、解析先验与训练期特权排序蒸馏。
3. 主要结果：先报告单行人交互规划实验的限定 Gazebo 阳性，再报告快速传感器级学习实验的正式阳性；把总体、基线、
   样本数、区间与门槛放在同一页，避免读者误把两项结果合并。
4. 讨论：一个简短小节说明后续独立四方法表征未复现普遍 Actual TEB 时间优势；学习方法的两轮 Gazebo 外部验证
   虽完整运行，但未达到相对 Actual TEB/DWA 的预注册综合优势门。可用一张压缩表，详细回执
   与失败归因放附录。非核心开发诊断可仅列在附录或不写入正文。
5. 结论：重申成立的限定贡献和下一步外部有效性工作；不以局限替代贡献段落。

## 可供改写的摘要核心句

“本文提出面向 Ackermann 移动机器人的候选级局部导航框架，利用可执行轨迹集合、候选条件
交互预测和硬安全验证构建解析规划方法，并进一步以训练期仿真特权信息蒸馏传感器级候选排序
策略。在三个冻结单反应式行人 Gazebo 模板中，解析规划方法相对固定 Actual TEB 的配对时间
下降 12.9288%；在四类冻结快速传感器级任务中，学习方法相对解析先验的失效计入时间下降
8.402444%，通过预注册主门。后续不同协议和 Gazebo 对照尚未建立一般传统规划器优势，
因此结论限定于上述研究总体。”

这段摘要是编辑素材。两项结果对应独立实现与实验，不能把规划方法的 Gazebo 收益写成学习
方法的 Gazebo 收益。正式论文的标题、摘要、章节标题、图题、表题和结论不用内部阶段编号；
若为复现需要，编号仅留在附录的证据索引。真实传感器部署、多人/OOD、
形式化安全与实车效果尚无证据，不写成完成项。
