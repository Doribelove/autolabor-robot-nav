- BPU 由唯一 operator_server 进程持有原 preview_worker.lock 与一对常驻 HBM，公平轮询
  三路最新帧，未选中的端口仍持续识别。相机进程与模型进程分离，分别加载匹配的 SDK 环境。
- 原 BpuEngine / detector_input / classifier_input / NMS / context_crop 保留，检测阈值 0.2，

- Qt 保留原完整 C++ 界面，视觉页视频顶部增加“端口 0 / 1 / 2”按钮。
  每个报文包含原图 JPEG 显示副本及该帧识别结果，AGX Qt 解码/绘框，不执行模型推理。
  同时报两个置信度：D 为垃圾检测，C 为五材质分类。空检测帧会清框。
- 端口切换清除旧图；请求代号和数值端口挡住迟到结果。图像/结果 session、sequence、
  原时间字段必须一致；拒绝未知模型、错误尺寸、坏框/概率、倒序及已退休会话。
- 只使用 SDK 读帧 monotonic 年龄做 500 ms 显示缓存门，保留 raw_stamp/hal_received_ns。
  未验证曝光时钟映射，不伪造 ROS acquisition stamp；推理耗时为板端处理时间。
  此直接预览接口没有发布 /fod/detections 或其他 ROS 检测/控制消息。
- 没有安装外参、深度、跟踪 ID 或地图位置，不把三路透视识别当作 BEV/完整环视验收。
