本次实现
distribution/j6m_bpu_navigation/surround/：
  contracts.py：帧身份、时钟映射、标定校验；不以接收时间伪装曝光。
  capture.py / native/capture.cpp：四路 SDK 生命周期、YUV stride/格式、
    缓冲回收、原始计数器、PYM/GDC 路径和独立设备锁。
  prepare_vio.py：私有 RX4->PYM->GDC 候选配置生成。
    供应商通用配置裁 1536 到 1280 行，已纠正为完整标定画幅；
    输出 runtime/surround_vio_candidate_20261020/，未上板。
  scheduler.py：四个最新帧槽，15/3/2 Hz 初始预算，倒车优先后路，
    500 ms 拒收，分类次数/时间预算，无持续排队。
  inference.py：复用原两份 HBM 与前后处理、驻留加载、原 BPU 独占锁。
    检测编译模型名仍 detector_zed，GAM 保留；此名称不代表依赖 ZED 输入。
  geometry.py：标定透视图、光学坐标->base、标定地面平面、源时刻 map 位姿、
    协方差、有效区域与距离过滤。无外参/定位时不生成地图目标。
  tracking.py：重叠图和无歧义双向匹配，保留多路证据；独立时刻确认、
    真实可见帧漏检计数、stale 保留、completed 墓碑、地图/会话切换清空。
  pipeline.py：整链协调、地图变化无需等待下一相机帧便失效旧目标，
    当前定位有效性独立报告，保留曝光/标定/模型/校正版本。
  display.py / preview_server.py：四画面、地面 IPM、Qt 和只读预览传输。
    后路不推理时仍可显示；显示线程与 BPU 分离，检测不在 BEV 上执行。
    原生服务的状态和预览图分别检查时效，显示失效不刷成实时。
  acquire_calibration.py / calibrate.py：后续显式相机标定采图、鱼眼内参、
    地面控制点外参候选求解；不自动激活候选值。
  demo.py / __main__.py：合成回放、doctor、显式 run 和 CLI。
  report.py：离线 P50/P95/P99、源帧龄、分类截断等汇总。
  bundle.py：仅制作本地源码/HBM/捕获库候选包，不部署。
  config/：真实标定、端口、时钟/SDK 路径默认未填写；无虚构外参。
