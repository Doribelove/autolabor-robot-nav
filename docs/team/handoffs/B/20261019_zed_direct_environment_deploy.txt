实测检查与真实限制
1. 原生编译安装退出 0，约 9.5 秒；不是复制 AGX 的 build/devel/install。
2. 板端 ldd 对 probe/Open Capture/HIDAPI 全部无缺失库。
3. probe --version 返回 Open Capture 0.6.0、HIDAPI 0.14.0、cuda_required=false。
4. 原生传感器枚举正常退出，serials=[]；不把“无设备”当作相机已接收成功。
5. 隔离 OpenCV SGBM 自检使用合成左右图，预期视差 16 px、实测中位数 16 px，
   21000 个有效测试点；仅证明 CPU 立体匹配依赖能执行，不是实际相机深度精度验收。
6. Noetic 的 sensor_msgs/Image、CameraInfo、Imu 导入通过，没有创建 ROS 节点。
7. check 和 probe 均因硬件缺口返回 20，在打开采集设备前退出。
8. 实际演练 activate -> rollback -> 无候选状态 -> activate，全部按预期；
   回退时实验 current 撤回，原文件/导航 current 仍一致。收尾本实验 current 已重新启用。
