J6M MID360 永久接收地址配置（2026-10-24）

授权与范围
用户要求创建永久生效的 MID360 接收地址。本次只保存 J6M eth1 的网络地址，
当前应用该地址并检查连通性、只读接收已有雷达 UDP 数据。不启停车辆 ROS、
导航、底盘或视觉服务，不启动 FAST-LIO，不改变车辆运动许可，不重启整机。

接收地址：192.168.1.100/24；掩码：255.255.255.0；不设置传感器默认网关。

持久方式与工具行为
使用系统厂商工具 hrut_ipfull 写入硬件持久配置，不修改易失 overlay 的网络文件。
已有且 enabled 的 hobot-defaultip.service 在开机执行 /usr/bin/defaultip.sh；
该脚本读取各网口 hrut_ipfull 配置并应用 IP/掩码，仅在网关临时文件存在时添加网关。
服务文件及启动脚本 SHA256 前后一致，没有重启该服务，以免扰动管理网口。

执行 hrut_ipfull s eth1 192.168.1.100 255.255.255.0 0.0.0.0 时，工具先保存了
IP 与掩码，再因不接受零网关退出 255；此非零返回已原样保留在证据中。
不能仅凭这个返回码认定所有字段均未写入。后续多次独立进程读取持久存储，
均返回 IP=192.168.1.100、mask=255.255.255.0、gw=0.0.0.0（未设置）。
hrut_ipfull g eth1 也会因无网关退出 255，但正确生成 /tmp/ip_ip_eth1 和
/tmp/ip_mask_eth1，不生成 /tmp/ip_gw_eth1；这与既有开机脚本的无网关路径一致。
原 eth1 未设置 IP，网关已为零；本次没有为雷达填充虚构的网关。
当前地址使用 ip address add 应用。未做断电或重启后的实际验收。

本轮数据是 UDP 接收统计，不是 ROS 话题频率、精度或逐包无丢失验收。
