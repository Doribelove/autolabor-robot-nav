## 已确认的代码问题

### 1. 把显示订阅者误当成第二个导航执行者

`pending_litter_cleaner_node.py::_preflight_locked` 要求
`goal_pub.get_num_connections() == 1`，否则返回：

```
move_base simple-goal bridge is not the unique subscriber
```

但是当前 `operator_navigation.rviz` 的 `Navigation goal` 是启用的 `rviz/Pose`
显示，订阅 `/move_base_simple/goal`；`rviz/SetGoal` 同时向该话题发目标。
`j6m_fastlio_navigation.launch` 中的 `/navigation_pause` 也订阅该话题，将请求
转换为带精确 GoalID 的 move_base action。因此正常的“桥 + 目标箭头显示”就有
两个订阅者。显示订阅并非另一个运动控制器。

读取原始源码 AST，直接执行原 `_fresh` / `_preflight_locked`，其余前置状态
全部设为有效，结果：1 个订阅者接受，2/3 个订阅者均以上述原因拒绝。
此验证不创建 ROS 节点、不调用服务、不发布消息。

这是与综合页能发目标、待清扫按钮不发目标高度吻合的确定性代码缺陷。
不能声称已取到用户那次点击的现场拒绝记录：本轮 SSH 连接
`192.168.10.100:22` 超时，板端日志不可达。本地最新 GUI 日志为
`log/nvidia_ui_20260911_021352/gui.log`，记录了综合页配置加载，但没有该按钮
的服务拒绝事件。当前拒绝只显示在页面文字，协调器也没有相应 ROS 日志记录。

### 2. 近处目标仅按距离跳过导航，没有先判断朝向

`_run_mission` 在距离不超过 1.50 m 时直接进入视觉交接，但
`_stage_visual_target` 随后要求目标方位在车头正前方 ±35° 内。
原函数离线复现：车辆 yaw=π、目标 map(1,0)、车辆 map(0,0)，即目标距车
1.0 m、位于后方，结果 ABORT，原因为 `stand-off heading misses target by
-180.0deg`，没有提交导航或启用视觉。

因此近不等于能够直接视觉接管。阿克曼车辆也不能靠原地旋转解决这个条件。

### 3. 现有视觉尾段不是普通视觉模式

当前待清扫任务会暂存选定 ID/map 坐标，开启额外的源帧/身份匹配及前向轨迹
10 cm 完成条件；普通视觉/语音入口则使用原视觉流程。两者并不完全等价。
导航期间目标重新识别或 ID 改变也可能影响旧 ID 的匹配，这属于后续接管风险，
不是本轮已确认的现场首段不运动原因。

## 提议（待用户确认，尚未实施）

1. 保留与综合页相同的 `/move_base_simple/goal → navigation_pause → move_base`
   入口。修正订阅者身份判断：必须有正确的执行桥，允许 Qt/RViz 显示及已识别的
   只读观察者；不能仅按连接总数判定执行者唯一性。原底盘、TEB、覆盖逻辑不变。
2. 点击清扫时固定本次目标的地图坐标及任务身份，以垃圾为任务目的地，生成距其
   默认 1.5 m、朝向垃圾的可达接近位姿。只在此模块使用 1–2 m 接管范围，不修改
   全局导航到达容差。若直线退让点不可达，检查有限候选接近点；不能直接把障碍或
   不可达栅格当停车目标。近处但侧后方的目标仍需普通导航调整至可接管位姿。
3. 达到接近范围且朝向适合视觉时，确认本次导航目标已结束或被精确取消、旧目标
   不会重发、车辆停车，再通过现有 FOD 仲裁入口交接。不能只按距离立即叠加视觉
   速度。未到达、规划失败、定位丢失及取消均保持明确失败/等待状态。
4. 按用户此次提出的“后续采用视觉伺服控制逻辑”，清扫尾段拟恢复使用普通视觉
   流程及其完成判据，不再额外强制之前的 map 10 cm 轨迹完成门。仍需在目标附近
   用新鲜且唯一的视觉证据确认所选垃圾，可重新关联检测 ID，但不能随意换成其他
   垃圾。任务成功依赖本轮视觉完成及停车，而非任意一次返回 GPS_ACTIVE。
5. Qt 显示中文阶段和原因，记录任务目标、导航目标/GoalID、距离、接管与拒绝原因。
   失败/取消保留清扫栏项目，只有本轮成功才删除对应项。

确认后补充隔离回归：实际桥与目标显示订阅共存；远点/近点/侧后方点；接近点无路；
精确目标取消及禁止旧目标重发；检测 ID 更新、无目标/多候选；成功/失败/取消；
普通综合页导航、普通视觉及覆盖不回归。之后本机构建、板端部署和现场测试需按
后续用户授权执行，离线测试不等于实车验收。
