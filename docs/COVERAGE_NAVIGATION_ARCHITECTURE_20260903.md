# 全覆盖导航当前架构（更新于 2026-09-04）

## 结论

当前架构不预先生成任务级可执行全局轨迹，并明确区分“进入某个区域的首条清扫线”和
“同一区域内相邻清扫线转场”：

```text
区域多边形
  -> 几何分解选择清扫方向
  -> 无路径 Dubins 时间代理排列并定向清扫线
  -> 首条线入场：Navfn 全局路径 -> TEB（一个普通导航 action）
  -> 清扫：TEB 跟踪有向直线，禁止倒车
  -> 相邻线转场：实时位姿 -> 一次直接 Hybrid A* -> 按 cusp 拆分 -> TEB
  -> 入口 hand-off gate -> 下一条清扫线
```

- 首条清扫线入场直接使用 Navfn + TEB，不再把 Navfn 路径切成滚动 Hybrid A* 块。
- 同一区域的后续线间转场不经过 Navfn，只从实时停车位规划到下一入口。
- 一条 Hybrid 连接由管理器按每个 cusp 拆成若干固定档位 action；每段均由 TEB 闭环
  跟踪，只有实测速度归零后才允许提交下一档位 action。
- cusp 是正常换挡点，不等于异常，也不会无条件触发搜索。每段停车后先检查实测位姿能否
  以同档、切向且半径不小于 1.35 m 接回缓存后缀；可接就裁掉旧锚点继续，不可接才从实测
  位姿到原清扫线最终入口重算完整剩余连接，而不是只重算到邻近 cusp。
- 默认只在新转场、连续偏离、阻塞或入口异常时重算。1 Hz 周期可检查路径，但不会无条件
  替换仍有效的路径。
- 入口位置、横向、航向或停车条件不满足时保持 `TRANSITING`，不会提前进入
  `SWEEPING`。入口异常恢复允许低代价短倒车，并限制总长和累计前进距离，拒绝大幅前进
  绕圈。

这套架构已经同步到权威工作区源码，并与当前 Qt、ROS 消息、J6M launch 和健康检查
适配；J6M 已部署 release `20260904_022107`。2026-09-04 首轮操作员参数实车实验未完成，
并暴露固定倒车 TEB 反号重置和入口恢复候选被后置规则拒绝；受限低速实车运动验收仍未
通过。
上一版仿真运动数据的适用边界见
[区内清扫线转场重复实验](COVERAGE_TRANSITION_EXPERIMENT_20260903.md)；该实验使用已删除的
自定义跟踪器，只能作为历史对照，不能证明当前 TEB 控制链的运动效果。

## 阶段职责

| 阶段 | 全局路径权威 | 速度控制权威 | 完成条件 |
| --- | --- | --- | --- |
| 某区域首线入场 | Navfn | TEB | move_base 成功后再由覆盖管理器检查入口合同 |
| 区内线间转场 | 直接 Hybrid A* | TEB | 进入 hand-off basin、立即取消当前 action 且实测停车 |
| 直线清扫 | 覆盖管理器 enforced path | TEB | 有向进度、越线和连续零速样本同时满足 |
| 入场异常恢复 | 受限 Hybrid A* | TEB | 恢复入口位姿；失败时有限重试后暂停 |

从 A 区完成后前往 C 区不是“线间转场”。A 区任务结束后，C 区是一个新的覆盖区域，
因此到 C 区首条线按普通 Navfn + TEB 入场处理。

## 生产控制链

静态地图模式的速度链如下：

```text
move_base + TEB -> /cmd_vel_teb
                    |
                    v
           hybrid_teb_command_mux
              所有阶段：只转发新鲜 TEB 指令
              Hybrid 转场：额外要求全局插件安全许可，
                           核对固定档位并硬限制曲率
                    |
                    v
             /cmd_vel_unlocalized
                    |
       静态定位门 -> /cmd_vel_navigation
                    |
       FOD 仲裁 -> /cmd_vel_safe
                    |
       NVIDIA 最终看门狗 -> /cmd_vel
```

`hybrid_teb_command_mux` 是必需的 fail-closed 输出门，但不是局部规划器，也不包含 pure
pursuit、Stanley 或其他路径跟踪控制律。Navfn、Hybrid A* 和覆盖管理器只提供参考路径，
实际速度始终由 move_base 内的 TEB 根据反馈实时求解。mux 使用 `map -> base_link` 仅计算
诊断偏差；M2 `/odom` 由覆盖管理器用于确认 cusp 和入口处真实线速度已经降到阈值。每条
新连接默认无许可，只有
`CoverageGlobalPlanner` 在最新 costmap 上校验当前位置和未来 3.0 m footprint 后，才以
1 Hz 发布新鲜安全许可；许可为 false 或超过 1.5 s 时立即输出零速。插件不再暗中生成一条
只有 move_base/TEB 看得到的新路径，连接失效后由覆盖管理器统一从实时位姿到原最终入口
整段重算。TF、路径或上游速度指令过期时同样输出零速；定位门、FOD 仲裁和最终看门狗
没有被绕过。

固定倒车 action 的 via-point 航向按“路径切向 + π”解释，使车辆前向朝向与倒车行驶
方向不再互相冲突。倒车命令只从 TEB 第一个优化边提取，避免跨过 cusp 附近的微小折叠；
前进和清扫仍保持 `control_look_ahead_poses=2`，以便从入口的小幅反向数值折叠并入前进线。
速度饱和前先检查原始命令档位符号，错误方向会 fail-closed 重置，不能被 `-0.0` 隐藏成
永久停车。

## 转场和异常恢复生命周期

1. 上一条线按有向终点、越线距离和实测零速完成，不要求倒回几何终点。
2. 使用实时位姿到下一入口调用一次 Hybrid A*，不使用任务开始时缓存的轨迹。
3. 完整带符号路径按 cusp 拆为固定档位 action；TEB 在各 action 末端减速，管理器确认实测
   零速后才处理下一 action。短 cusp 段除进入位置/航向容差外，还必须达到有向进度，不能因
   `0.25 m` 位置容差而在只走几厘米时提前验收。
4. cusp 停车后先对下一缓存段做同档切向续接检查。若 0.30 m 内存在航向误差不超过
   0.10 rad、曲率半径不小于 1.35 m 的接点，就从实测位姿重建首边并继续；否则丢弃整个旧
   后缀，从实测位姿直接 Hybrid A* 到原最终清扫入口。cusp 本身不计作异常事件。
5. 全局插件以 1 Hz 校验当前连接未来 3.0 m；无效时撤销安全许可，命令 mux 立即零速。管理器
   同时观察相对当前路径局部切向的横向与航向误差；失效或连续超差后取消当前 generation，
   并从最新位姿统一重算。
6. 一旦进入外层入口 hand-off basin（位置/横向/航向分别不超过
   `0.40 m / 0.40 m / 0.436332 rad（25°）`），管理器立即精确取消当前 action，使 TEB 减速；不再追赶
   Hybrid A* 的内层采样终点。新鲜 `/odom` 连续确认停车后直接验收入场并切入下一清扫线。

若首线 Navfn + TEB action 结束时仍不满足入口合同，异常恢复使用 Hybrid A*：前进按
0.20 m/s、倒车按 0.80 m/s 计时，换挡代价 0.15 s；候选总长不超过 4.0 m，累计前进不
超过 1.20 m。它允许为几何可行性做短前进弧，但不接受大幅前进绕圈。恢复失败不会跳过
清扫线，而会在有限重试后暂停。

## Qt 适配

Qt 继续使用现有覆盖规划、开始、暂停、继续和取消服务，并已重新按扩展后的消息生成。
状态区同时显示清扫任务速度和专用转场前进/倒车速度、角速度、加速度与 Hybrid 跟踪前视；
速度安全提示按两类参数中的较大值校验看门狗能力。界面提示明确说明首线使用 Navfn + TEB、
区内转场使用直接 Hybrid A*，避免把两个阶段误认为同一种导航。

## 1 Hz 对照与选择

当前 TEB 固定档位架构已做仅改变 `hybrid_replan_every_cycle=true` 的 A 区对照。首个固定
前进段收到 6 次 1 Hz 新路径，mux 每次都出现路径/安全许可/TEB 指令未同时新鲜的归零窗口，
3 s 内只前进 0.092 m，触发无进展取消；之后的入口恢复候选因总长 4.50 m 超过 4.00 m
硬边界被拒绝，任务在 43.00 s 仿真时刻进入 `PAUSED`，没有完成首个转场。事件版同地图、
同初值和参数则完成全部三次转场，并记录 0 次 1 Hz 无条件搜索。因此当前生产保留事件搜索；
move_base 的 1 Hz 调用只校验/复用正在执行的连接，不重新运行 Hybrid 搜索。

  `0.40 m / 0.40 m / 25°`；中间 cusp 保持 `0.25 m / 0.20 rad`。外层航向比搜索区域多
  5°用于容纳跟踪误差。30° 外层门在试验中会把约 28.5° 的姿态直接交给禁止倒车的清扫

  停车累计 2.704--4.134 s，TEB 相对 Hybrid 参考的 P95 最大偏差为 0.034--0.043 m。
