# GPS 禁入区与 FOD 目标点

AGX 单机完整 GPS 导航启动时自动提供本模块。禁入区初始为空且未启用；普通 GPS 导航入口、双天线定位及速度参数不变。

## Qt 操作

### GPS 禁入区

1. 打开“GPS 禁入区”，点击“新增多边形”。
2. 按边界顺序输入经度、纬度，逐个“添加顶点”。至少三个点，末点自动连回首点。“填入车辆 GPS”可以填入当前定位。
3. 可以选择并删除顶点、上下移动顶点顺序，或者删除整个多边形。交叉、共线或不足三个顶点的区域不能应用。
4. 勾选“启用通行范围 / 禁入区”，车体外沿距离默认 **1 米**，点击“应用到导航”。编辑中的修改在点击应用后生效；已有路线会根据新禁区重新选取绕行子目标。
5. “保存 GPS 禁入区”写入 JSON。“加载 GPS 禁入区”先载入编辑区，再点击应用。“导出禁入区栅格地图”同时保存 PGM、YAML、GPS JSON；默认每格 0.1 米。

栅格文件描述人工设定的虚拟禁入区，并包含 GPS 原点。白色表示没有人工禁区，不能代表雷达已扫描到可通行地面。跨次启动应加载 GPS JSON，由当前 GPS 原点重新投影；不要把旧原点的 PGM 直接作为新场次定位地图。

自动保存位置：`~/.config/autolabor/gps_keepout.json`。启用状态和已应用区域会在重启后恢复。取消勾选并应用，或删除区域并应用，都会清除相应虚拟障碍。

### 机场地图 ZIP

“GPS 禁入区 → 导入机场地图 ZIP”支持本次供应方的 `第二次修改.zip`：

- 使用 WGS84 面图层 `GHWJ` 作为范围，扣除 `LH` 绿化、`building` 建筑、`Sbuilding` 附属建筑和 `construction_` 施工区，保留全部内部空洞。道路及跑道中心线仅显示，不推算通行宽度。
- 绿色范围内为候选通行区域，范围外和内部空洞均禁行。长距离 GPS 选点、全局和局部代价地图、视觉靠近及穿越共用这些边界，沿用已有的车体尺寸及外沿距离。
- 导入后预览，点击“应用到导航”才启用；导入本身不发送目标。可以叠加手工禁入区。“移除机场地图”只删除地图，保留手工多边形，点击应用后生效。
- FOD 页预览与导航 RViz 显示地图边界及道路参考线。仍通过原有 FOD 选择按钮显式发送目标。
- 保存的 JSON 内嵌完整 WGS84 几何，启动时按当前 GPS 原点转换，不依赖原 ZIP 路径。加载机场地图时栅格导出默认 **0.5 米/格**；原导航实时代价地图仍为 0.1 米，不扩大滚动窗口。
- ZIP 导入依赖 `python3-pyshp`，未安装时只影响导入功能。手工多边形及已转换的 JSON 不需要该依赖。

该图是规划数据。三个实测 FOD 坐标均落在同一可通行连通区域，但这不等于已测定图纸与实地边界的配准误差。现场仍需检查图中绿化/路沿与车辆定位的对应关系。地图不能替代雷达对临时障碍物的检测。

### FOD 目标点

打开“FOD 目标点”，粘贴以下顺序的数据，点“导入文本并显示”；也可导入 CSV/TXT：

```
pt0 104.3892865 30.29387435
pt1 104.3898634 30.29726472
pt2 104.3904909 30.30145079
```

顺序为 **点名、经度、纬度**，支持空格、Tab、逗号。支持测量 CSV 的“点名、B、L”字段和度分秒，UTF-8/GB18030 编码。目标显示在列表、位置预览和导航 RViz 地图中，列表距离随 GPS 更新。

选择列表中一行，或点击“选择最近 FOD”，然后点击“发送所选 FOD 导航目标”，进入原有 GPS 目标发送流程。导入、显示和选中目标均不会自动启动导航。这些点不会变成禁区顶点。

自动保存位置：`~/.config/autolabor/agx_gps_map_targets.json`。

## 导航接入

- `/gps/keepout/command`：编辑、保存、加载、导出、目标点导入服务。
- `/gps/keepout/state`：当前 GPS 原点和已应用的局部多边形。
- `/gps/keepout/polygons`：加入全局、局部 costmap 的已扩张区域。
- `/gps/keepout/markers`、`/gps/targets/markers`：RViz 显示。
- `/gps/targets/selection`：选中 FOD 的地图高亮，不发送导航目标。

禁入区填满整个多边形，依据 1.6 × 0.8 米车体留出边界余量。长距离 GPS 子目标绕行使用车体外接圆，转向时也保留外沿距离；局部 TEB 继续使用原有矩形 footprint。视觉靠近和最后 0.8 米穿越也遵守已启用的禁区，接近边界时停止该方向输出并显示禁区原因。

目标处于通行范围外、禁区或预留范围内时拒绝该目标。修改边界导致现有路线无解时取消该路线，报告 `KEEPOUT_BLOCKED`，需要修改区域或选择可达目标。功能未启用，或没有机场地图且禁区为空时保持原有行为。

## 本次验证

非运动测试覆盖：五种绕行任务（矩形、多个、凹形、重叠和大区域）、外沿余量、视觉前进/倒退、不可达目标、坐标转换、栅格方向、CSV 解析；隔离 ROS 服务的保存/恢复/无效配置保留/导出/导入不发车；真实 costmap 插件全局与滚动地图填充/清除；Qt 顶点增删/排序、FOD 选择与显式发送。原 GPS 和相机模式管理的相关回归测试通过。尚未进行新增围栏功能的实车绕行测试。

机场地图增量覆盖 ZIP 坐标系和完整性、内部空洞、外部禁止通行、窄通道不连通、附加手工禁区、跨原点转换、栅格及插件的反向填充、移除/禁用恢复、Qt 隐藏页加载后的缩放。实际 ZIP 的 pt0、pt1、pt2 之间六条双向滚动目标路径离线验证全部完成，车体外沿与边界的最小余量均大于 1 米；这属于几何路径仿真，不是实车转向和动态避障测试。
