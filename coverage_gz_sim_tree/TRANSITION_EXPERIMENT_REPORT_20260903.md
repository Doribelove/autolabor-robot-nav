# 区内清扫线转场重复实验（2026-09-03）

## 结论与口径

本报告是已经删除的自定义 cusp-aware 跟踪器架构的历史结果，不能用于验收当前 TEB 固定
档位 action 架构。该历史事件触发架构在 A、C、自定义 D 三个区域各运行 3 遍，共计 39 次“上一条清扫线终点到
下一条清扫线入口”的转场。39/39 全部完成，最大 8.492 s，均小于本轮接受的 10.0 s
上限；没有一次事件重规划、长时间停车重规划或大幅前进绕圈。

首条清扫线入场和区域 A→C 等点到点导航明确排除。它们作为独立问题记录，不参与本报告

## 汇总观察

1. 典型连接是 4.24 m 的三点调头。相邻清扫线入口直线距离仅约 0.85 m，但 1.35 m 最小
   转弯半径使 Ackermann 车辆必须使用短前/倒/前或倒/前/倒组合；这不是不必要的绕圈。
2. A 和 D 的 15 次转场均为 6.49–7.07 s。C 的第一对清扫线偶尔生成 4.54–4.69 m、
   3 次换挡连接，因此为 8.0 s 左右；C 第 1 遍线2→3因末段以 0.04 m/s补航向达到
   8.492 s，但仍连续完成，没有重规划。
3. 曾把全程最低速度提高到 0.08 m/s，结果 C 第一转场偏离到 0.700 m并取消重规划，
   总耗时 12.498 s；该参数已撤回，失败证据保留在
   `results/tune_C_min08_20260903_160205`，不计入正式统计。
4. 转场实际 Hybrid 跟踪最大误差为 0.271 m。TEB 后台局部路径相对 Hybrid 全局路径的
   TRANSITING P95 最大偏离在各遍为 0.446–1.026 m，并有 3.841 m 的单点切换离群；它
   明显大于真实 Hybrid 跟踪误差。因此 TEB 在转场中不能重新获得速度控制权。清扫状态
   的 TEB P95 最大偏离为 0.140–0.254 m。

- 从 A 区结束到 C 区属于新的点到点导航任务，不属于清扫线转场；不计入本文。
- 早先“Navfn 拓扑 + 10 m 滚动 Hybrid”从 A 到 C 在窄口发生 80,000 expansions / 3 s
  超时并暂停。该拆解现已从正常首线入场中删除，首线直接 Navfn+TEB；长距离点到点效果
  尚未在本轮继续验收。
- D 区中央到首线的 Navfn+TEB 出现短距离调姿速度符号抖动。它不改变 39/39 转场结论，
  但在实车部署前仍需单独处理和验证。

## 仿真限制

loopback ROS/Gazebo master 完成，没有连接或部署 J6M，不能替代实车验收。
