## 隔离边界

- 实验产物只在本目录；Qt 源码/构建只在候选版对应目录，运行经 `scripts/optimized.sh run`。
- 远端只使用 `/map/robot_j6m_optimized_20260905/bpu_lab_20260905`。
- 不修改原项目、系统库/驱动/服务、导航 chroot、发布链接或默认后端。
- 实验不发布 ROS 控制或生产检测话题；不打开 CAN 或启动底盘。
- 用户已确认完全静止并随后授权启动相机显示；已进行独立 RGB/Qt 测试。
  轮速反馈、深度与定位问题尚未排除，不自动重启完整导航。
- 新模型精度、完整延迟和故障路径未通过前，不能声明迁移完成或 GPU 已释放。

## 顺序

1. 下载并校验官方 FCOS NASH_M HBM，检查实际编译/运行库版本与输入输出。
2. 在隔离远端目录验证离线 BPU 推理；只使用项目私有、兼容的运行库。
3. 导出现有垃圾检测与材质分类的固定输入 ONNX，核验模型/算子/类别契约。
4. 在可用的 J6M 工具链中量化、编译与原模型逐样本比较；GAM 不支持时再评估训练 FCOS。
5. 接入限频、最新帧的跨机推理和原帧深度匹配，静态验证后才允许切换后端。

FCOS 参考模型为 80 类通用检测，不允许伪装成现有垃圾模型或五材质分类器。
参考权重遵守仓库许可，仅用于内部验证，不对外分发。
