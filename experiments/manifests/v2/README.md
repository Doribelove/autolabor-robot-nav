# FAM-TEB V2 manifest root

V2 scene manifests, splits, preregistrations and amendments belong below this directory.
The directory is intentionally separate from frozen T11/T12 manifests.

No V2 formal experiment is preregistered yet. V2-04B calibration-only candidates live under
`calibration/`; their 90/90 screen episodes are complete, but the final fail-closed assessment
keeps Anchor freeze blocked. They may not select on validation/test scenes and are not formal
results. A V1 runner must reject resources from this directory.
